# 안전보건 콘텐츠 허브

산재예방 글로벌 서포터즈(안전보건공단) 활동으로 제작된 웹 프로토타입입니다.
공단 유튜브 영상을 카드뉴스·큐레이션 대시보드 형태로 재가공해, 이용자가 자신의 업종·상황에 맞는 안전 콘텐츠를 빠르게 찾을 수 있도록 돕습니다.

🔗 **사이트 바로가기**: https://아이디.github.io/저장소명 (배포 후 이 링크로 교체)

## 이 사이트에서 할 수 있는 것

- **카드뉴스**: 배정받은 영상별 핵심 내용을 예고편 형태의 카드뉴스로 확인
- **영상 찾기**: 업종 → 위험요인 2단계 선택으로 맞춤 영상 추천
- **안전 상식**: 위험요인별 몰랐던 사실을 플립카드로 확인
- **미니 퀴즈**: 배정 영상 내용을 바탕으로 한 5문제 퀴즈
- **서포터즈 소개**: 팀 소개 및 활동 안내

## 구조

별도 서버나 빌드 과정 없이 `index.html`을 열면 바로 작동하는 정적(static) HTML/CSS/JS 사이트입니다.

```
index.html          메인 페이지 (전체 사이트)
mascot-main.jpg      히어로 영역 마스코트 이미지
cn07-01~07.jpg       7번 영상 카드뉴스 (7장)
cn09-01~09.jpg       9번 영상 카드뉴스 (9장)
```
